SETUP REQUIRED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before going live, add your Google Maps API key:

1. Get key: https://console.cloud.google.com/
2. Enable: Maps JavaScript API + Geocoding API
3. Add to .env file (VITE_GOOGLE_MAPS_API_KEY=...)
4. Secure with HTTP referrer restrictions

See GOOGLE_MAPS_SETUP.md for detailed instructions.
